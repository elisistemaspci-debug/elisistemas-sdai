# Sistema de Vistoria e Relatório Técnico NBR 17240

Sistema web desenvolvido em **Python** utilizando **Streamlit**, focado na gestão, inspeção preventiva, cadastro de clientes e emissão de relatórios técnicos de Sistemas de Detecção e Alarme de Incêndio (SDAI), em conformidade com as normativas técnicas aplicáveis.

## Funcionalidades
- **Vistoria & Relatório Técnico:** Preenchimento de inspeções e geração de dados operacionais.
- **Cadastro de Clientes & SDAI:** Gerenciamento de informações de clientes e equipamentos.
- **Gestão de Empresa:** Configuração de dados corporativos e emissores.
- **Chamados e Usuários:** Controle de acesso e histórico de ocorrências.
- **Exportação/Importação:** Suporte a salvamento de rascunhos via arquivos JSON.

## Tecnologias Utilizadas
- Python
- Streamlit
- ReportLab (para geração de PDFs)
